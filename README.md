## Project Summary
This repository showcases a comprehensive portfolio of three descriptive analytics projects designed to extract actionable business insights from complex datasets. It includes a detailed IBM Cognos Analytics report based on Superstore/SuperStore data, an in-depth Python-based Flipkart sales descriptive analysis, and an upcoming Power BI dashboard focused on detecting financial fraud.

## Files and Folders
* README.md: This project documentation file contains the overview, folder structure, and key findings.

* report/: Contains the final descriptive analysis PDF reports, including the Flipkart Sales Analysis (Adnan_Ahmad_1250258048_DescriptiveAnalyticsReport.pdf) and the Business Analytics Lab Record (DA Lab Record.pdf).

* screenshots/: Images and visual captures used within the respective reports.

## Key Findings
1. Flipkart Top Performers: Across the 100-order sample, "Jeans" emerged as the best-selling product with 29 units sold, while "Beauty" stood out as the leading category, contributing 26.5% of the total revenue.   

2. Flipkart Discount Impact: Analysis revealed a negligible correlation (0.01) between discount depth and quantity sold, indicating that heavier discounting did not drive higher unit sales or improve customer ratings.   

3. Superstore Customer Loyalty: The Superstore dataset showed exceptional customer retention, with 98.5% of the 793 active customers placing repeat orders, resulting in an average revenue of $2,897 per customer.   

4. Superstore Regional Sales: Total sales for the Superstore dataset reached $2,297,200.86, with the West region leading geographical demand by generating $725,458 in revenue.
